# Samples

Instrument samples from the [tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments) project
(npm packages `tonejs-instrument-*-mp3` by Makefully Studios), MIT license.
Re-encoded for Composer: mono, silent tails trimmed, length capped with a short fade-out.
Files are named by MIDI note number; `manifest.json` lists the notes available per instrument.
